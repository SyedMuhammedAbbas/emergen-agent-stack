## Emergen application

Before production, load test systems with expected traffic patterns.

Measure:

- average latency;
- P95 / P99 latency;
- error rate;
- requests per second;
- CPU, memory, and database connection usage.

Run baseline, stress, and soak tests for production-bound services.

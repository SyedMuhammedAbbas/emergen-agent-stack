## Primary documentation

- **W3C WCAG 2.2**: https://www.w3.org/WAI/standards-guidelines/wcag/
- **W3C WAI-ARIA**: https://www.w3.org/WAI/standards-guidelines/aria/
- **MDN Accessibility**: https://developer.mozilla.org/en-US/docs/Web/Accessibility

## Framework-specific

- **React Accessibility**: https://react.dev/learn/accessibility
- **Next.js Accessibility**: https://nextjs.org/docs/architecture/accessibility
- **React Native Accessibility**: https://reactnative.dev/docs/accessibility
- **Flutter Accessibility**: https://docs.flutter.dev/ui/accessibility-and-internationalization/accessibility

## Emergen application

Require:

- semantic HTML on web;
- keyboard navigation;
- visible focus states;
- form labels and error association;
- sufficient color contrast;
- screen reader support where applicable;
- appropriate touch target sizes on mobile.

Use WCAG as the authoritative accessibility reference.

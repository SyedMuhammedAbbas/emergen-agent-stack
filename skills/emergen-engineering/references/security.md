## Emergen application

Apply Emergen security standards for:

- input validation;
- authentication and authorization;
- secrets management;
- rate limiting;
- secure headers;
- safe error responses;
- file upload validation;
- webhook signature verification.

Use OWASP guidance as the authoritative security reference.

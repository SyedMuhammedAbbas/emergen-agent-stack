# TypeScript Official References

## Primary documentation

- **TypeScript Handbook**: https://www.typescriptlang.org/docs/
- **TypeScript Compiler Options**: https://www.typescriptlang.org/tsconfig
- **TypeScript Strict Mode**: https://www.typescriptlang.org/tsconfig#strict

## Emergen application

Require:

- `strict: true` in production projects unless explicitly documented otherwise;
- type safety over `any`;
- validated external input with typed DTOs/interfaces;
- explicit return types for public APIs where it improves clarity.

Follow official TypeScript guidance for configuration and type system usage.

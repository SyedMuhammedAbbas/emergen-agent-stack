## Emergen application

Require multiple testing levels where applicable:

1. Static analysis (TypeScript, ESLint, formatting)
2. Unit tests (business logic, utilities, services)
3. Integration tests (API + database)
4. E2E tests (critical user flows)
5. Load tests (production-bound systems)

Prioritize high-value coverage over arbitrary percentage targets.

## Emergen application

Follow official PostgreSQL guidance for:

- relational schema design;
- constraints and data types;
- indexing strategy;
- transactions and isolation;
- query performance.

Apply Emergen database standards for naming (`snake_case`), migrations, pagination, and avoiding production schema sync.

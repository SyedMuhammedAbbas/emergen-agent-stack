## Emergen application

Follow official NestJS guidance for:

- modular architecture;
- DTO validation with class-validator;
- guards, interceptors, and filters;
- dependency injection;
- testing with Jest and Supertest.

Apply Emergen backend and API standards for feature modules, response shapes, auth, transactions, and idempotency.

# Pre-Development Checklist

## Requirements
- [ ] User flows understood
- [ ] Roles/permissions understood
- [ ] Edge cases identified
- [ ] Third-party integrations identified
- [ ] Performance expectations identified

## Architecture
- [ ] Existing architecture inspected
- [ ] Correct feature/module identified
- [ ] Existing reusable code identified
- [ ] Data flow understood

## Database
- [ ] Entities/relationships understood
- [ ] Constraints identified
- [ ] Index needs identified
- [ ] Migration plan identified

## API
- [ ] Endpoints identified
- [ ] DTOs identified
- [ ] Authentication/authorization identified
- [ ] Error contract identified
- [ ] Pagination identified

## UI
- [ ] Loading state
- [ ] Skeleton state where appropriate
- [ ] Empty state
- [ ] Error state
- [ ] Success state
- [ ] Responsive behavior
- [ ] Accessibility

## Testing
- [ ] Unit tests identified
- [ ] Integration tests identified
- [ ] E2E tests identified
- [ ] Load testing need assessed

## Final step of every run (mandatory)
Before finishing, post one issue comment in exactly this format. It is for the board; nothing reads it into Odoo, so never name it a "run summary". Any rule above that mentions the run summary means this wrap-up for you.

```
### Wrap-up
- Agent: <your name>
- Done: <1-3 lines, plain language, no em dashes>
- Files: <paths of what you produced, or "none">
- Needs the board: <the approval or answer you wait for, or "nothing">
```
